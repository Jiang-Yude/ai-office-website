02

Codex 基本介紹

Codex 是什麼

  • OpenAI 出的 Agent 工具，用 ChatGPT 帳號登入，免費（含在 ChatGPT 訂閱裡）
  • 跑在你的終端機裡，能讀檔、改檔、上網、執行指令
  • 支援多種任務模式：寫文章、整理檔案、做網頁、規劃流程
  • 核心特色：權限可控、記憶可累積、技能可擴充
實際安裝操作我會直接帶大家在電腦上做，這頁不細講。
03

三層權限 ⭐

三層權限對照表

UI 名稱能做什麼不能做什麼
◎ Read Only
唯讀模式		 讀檔、瀏覽結構、討論規劃 不能改檔、不能執行修改指令、不能聯網
© Auto
自動審核（預設）		 在「當前 repo + 暫存區」
讀檔、改檔、跑本地指令		 不能動工作區外的檔；預設不聯網
◎ Full Access ⚠️
完整存取		 沒有 sandbox 限制：寫任何路徑、聯網、執行任何指令 沒有技術邊界

CLI 內輸入 /approvals 可即時切換。

⚠️ 真實案例：完整存取出事

警示

之前有學員用 Codex 串 NotebookLM 跑沙盒下載，
開了 完整存取權限 結果出問題。

教訓——完整存取權限的判斷標準：

「我清楚知道我在做什麼，且願意承擔後果」才開。
不清楚就留在「自動審核」等級就好。

04

記憶機制 ⭐

Codex 的記憶分兩種

類型由誰寫怎麼開啟
手動記憶
你給 AI 的偏好、規則		 你 Codex 設定 →「自訂指令」
自動記憶
AI 自己整理你說過的重點		 它 Codex 設定 →「個人化」開啟

越重要的偏好，越要手動寫。

手動記憶（自訂指令）

在 Codex 設定 →「自訂指令」裡：

向 Codex 提供專案的額外指示與背景資訊。
這就是「全域 AGENTS.md」——所有專案通用的偏好。

另一種：專案 AGENTS.md

  • 位置：專案根目錄的 AGENTS.md
  • 內容：這個專案專屬的規則

→ 江江 AI 辦公室裡的 agents.md 就是這個東西。

自動記憶（個性化）

在 Codex 設定 →「個人化」裡開啟。

三條原則

  1. 對話過短不記錄
  2. 記錄會消耗額度
  3. 它不見得記到對的重點

⭐ 最關鍵的問題

你怎麼知道它有沒有記錯？

  • 定期檢查：「列出你最近記了什麼關於我的事」
  • 發現記錯：「這條請忘掉」或「這條改成 XXX」
  • 記不到重點：改用自訂指令手動寫
規則：重要的事手動寫，自動記憶當輔助。

教學員
怎麼問 Mika ⭐

為什麼這段是核心

AI 辦公室的本質：
你不用記功能
AI 會教你它有什麼

所以今天的重點是教你怎麼問 Mika，讓 Mika 自己介紹助理。

三句萬用問句

  1. 「這裡有哪些助理可以幫我？」
    → Mika 列出 21 個助理 + 各自用途
  2. 「我手上有一份 XXX，可以怎麼處理？」
    → Mika 推薦對應技能包 + 操作步驟
  3. 「我想 XXX，有沒有什麼能幫我？」
    → Mika 找出相關技能包 + 主動建議

萬用咒語

不知道要說什麼時
「我要怎麼開始？」

Mika 永遠會回應，永遠會引導下一步。

GitHub 進階補充

為什麼今天提 GitHub

  • 網頁做出來要放哪裡？→ GitHub Pages 免費好選擇
  • 技能包想分享給朋友？→ GitHub 是最方便的傳遞方式
  • 明天 AI 工具又有新版？→ 很多更新都在 GitHub 上

GitHub 的本質

GitHub 最一開始是
「備份管理程式碼版本」的工具

網頁、技能包、文件都可以放上去——功能比較多。

缺點是：網頁版面跟網址都不算最漂亮。

其他做網頁的服務（Vercel、Netlify 等）今天先不講。

GitHub 的多種用途

用途說明
版本管理你改了什麼、什麼時候改、改錯可以救回來
網頁發布GitHub Pages 免費、永久、有網址
技能包分發把你的 SKILL.md 放上去，別人下載就能用
接收更新通知別人改了你能訂閱通知
接案作品集把作品放上去，求職、接案都看得到
